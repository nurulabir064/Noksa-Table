# Noksha Table

A fictional premium Bengali dining house concept website built with React, Vite, React Router and Tailwind CSS 4.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Notes
- The restaurant, its location and all menu items/prices are fictional sample content.
- Images are illustrative remote Unsplash images.
- Reservation and contact forms are frontend demonstrations only. They do not send or store data.
- No real booking, address, phone number, awards, reviews or business history are claimed.
